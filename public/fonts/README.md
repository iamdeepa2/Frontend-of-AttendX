# Satoshi

Satoshi variable WOFF2 (normal, weights 300–900), downloaded from the official
Fontshare CDN. Served locally so typography does not require a third-party
request at runtime.

Font and licensing information: https://www.fontshare.com/fonts/satoshi

Official stylesheet: https://api.fontshare.com/v2/css?f[]=satoshi@variable&display=swap
